# 🎓 StudyMate AI

StudyMate AI is a student productivity website designed to help students manage their studies, tasks, notes, and focus time using simple tools.

## 🚀 Features

✅ Study Task Planner  
✅ Add and Delete Tasks  
✅ Personal Study Notes  
✅ Pomodoro Focus Timer  
✅ Dark / Light Mode  
✅ AI Tools Section  
✅ Responsive Design for Mobile and Desktop  

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
